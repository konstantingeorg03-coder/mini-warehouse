# Mini Warehouse 📦

A simple inventory app for small shops that track their stock in a notebook or Excel.

## Problem
Small shop owners don't know exactly what they have in stock, how much it is worth, and when a product is running out.

## Features (version 1)
1. **Register and login.** Each user sees only their own warehouse.
2. **Add a product:** name, purchase price, sale price, quantity, description, minimum quantity (default 10).
3. **List** of all products.
4. **Sale:** the quantity decreases.
5. **Delivery:** the quantity increases.
6. **Edit** a product.
7. **Delete** a product.
8. **Summary:** total products and total stock value.
9. **Low stock alert:** if the quantity is below the minimum, the product is shown in red.

## Tech
HTML, CSS, JavaScript (ES modules, SPA), REST API
